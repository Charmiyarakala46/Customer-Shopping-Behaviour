# Customer Shopping Behaviour Analysis

## Project Overview

An end-to-end Data Analytics project focused on understanding customer purchasing patterns, shopping preferences and customer behaviour.

This project uses Python, SQL, PostgreSQL and Power BI to transform raw customer data into meaningful business insights.

## Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook
* PostgreSQL
* SQL
* Power BI

## Project Workflow

### 1. Python – Data Exploration and Cleaning

* Loaded the customer shopping dataset.
* Explored data structure and columns.
* Identified missing values.
* Handled missing values using appropriate techniques.
* Cleaned and prepared the dataset.

### 2. PostgreSQL & SQL – Data Analysis

* Imported cleaned data into PostgreSQL.
* Analysed customer purchasing behaviour.
* Compared subscription and non-subscription customers.
* Analysed discounted purchases.
* Segmented customers based on previous purchases.
* Identified top-selling products by category.
* Analysed customer spending patterns.

### 3. Power BI – Dashboard

* Connected Power BI with PostgreSQL.
* Created measures and visualisations.
* Developed an interactive dashboard.
* Presented customer shopping insights visually.

## Dataset Description

The dataset contains customer information such as:

* Customer ID
* Age
* Gender
* Item Purchased
* Category
* Purchase Amount
* Location
* Season
* Review Rating
* Subscription Status
* Payment Method
* Previous Purchases
